2026년 11월 26일, 첫 기록을 시작합니다.

## 존재 이유
인간과 세상을 탐구하고, 발견한 것을 표현하며, 그 과정과 결과를 공유합니다. 완성된 결과뿐 아니라 질문, 가설, 시행착오, 개선 과정도 기록합니다.

## 탐구 영역
- 인간의 감정, 욕망, 행동과 모순
- 문학, 카피라이팅, 광고와 창작
- 아이디어의 검증과 사업 실험
- 재사용 가능한 도구와 방법론

## 공개 원칙
관찰과 가설, 근거가 있는 사실을 구분합니다. 개인 정보, 고객 기밀, 제3자의 권리로 보호되는 자료는 공개하지 않습니다. 자료별 라이선스가 명시되기 전에는 별도의 재사용 허락을 부여하지 않습니다.
